# Limitations

- faster-whisper inference remains local-only and never downloads weights implicitly. In the audited environment, `tiny`, `small` and `base` weights are cached; other installations must prepare the selected model explicitly.
- The fallback VAD is energy-based; it is not a replacement for a trained VAD.
- Word-level code-switching across English, French and Arabic is an experimental lexical indicator, not validated language classification.
- Rule-based semantic extraction is intentionally conservative and incomplete.
- Offline Whisper inference is not native streaming. The WebSocket contract documents a chunked mode but does not claim real-time streaming performance.
- Word-level decoder probabilities add heuristic uncertainty evidence when available, but thresholds remain uncalibrated. The selective re-decode policy now reacts to the current heuristic's high band (0.30 raw score) and accepts an acoustic alternative only when two bounded decoding configurations agree, unless verified context provides a measurable reranking margin. This is a conservative engineering gate, not a calibrated error probability or proven WER improvement; reviewed segment labels and a leakage-safe held-out split are still required.
- CPU latency depends on model size, audio duration, and local hardware.
- The current downloaded ARen subset has 10 source utterances (5 Arabic, 5 English) in clean, telephony-bandlimited and synthetically noisy conditions. It is a smoke/diagnostic set, not a statistically conclusive ranking.
- ARen does not provide speaker IDs, intent labels or self-correction annotations. The current benchmark therefore cannot validate speaker-disjoint generalization, intent accuracy, or correction usefulness on spontaneous self-corrections.
- Synthetic telephony/noise is not equivalent to real device, codec, room or microphone noise. French has been measured on only 20 clean FLEURS test clips, which is too small to represent conversational French.
- A separate FLEURS test sample now contains 20 clips per language. Individual speaker IDs are unavailable. The viewer API exceeded its Parquet scan limit or timed out, so the downloader streams official archives and deterministically retains the first 20 unique transcripts in each locale. These scores are held out from validation-based threshold selection, but are not a full-split estimate.
- The controlled base E0–E3 test run accepted one useful and zero harmful corrections among 60 clips. Its only useful correction was French; this single outcome does not establish reliable WER improvement. The earlier validation follow-up was exploratory because the confidence margin was selected after inspecting that same validation set.
- FLEURS is clean, read speech. It has no labels in this project for spontaneous self-corrections, real code-switching, intent, or real-world noisy speech. Segment-level annotation templates for development and test remain unreviewed; no calibration claims are warranted.
- Do not market EchoMind as a reliable “self-correcting” system. The separate 60-clip test sample contains one reference-improving automatic correction, but it is not human audio-reviewed and is insufficient to estimate correction reliability. Describe the product as local multilingual ASR with experimental selective re-decoding.
- `config/*.yaml` files are not currently loaded by the runtime. Effective settings come from Python defaults/options; `config/thresholds.yaml` is stale (0.40/0.65) relative to the effective heuristic thresholds (0.20/0.30). Treat this as an incomplete configuration feature, not as the benchmark configuration.
